# 🚀 Anmol Chauhan — Full Stack Portfolio

A modern, responsive full-stack portfolio website built to showcase my projects, technical skills, experience, and development journey.

The portfolio features a React-based frontend, Node.js/Express backend, and MongoDB database for handling dynamic data and contact form submissions.

---

## 🌐 Live Demo

portfolio-website-alpha-one-52.vercel.app


---

## ✨ Features

- 🎨 Modern dark-themed UI
- 📱 Fully responsive design
- 👨‍💻 Personal profile and introduction
- 🛠️ Technical skills showcase
- 💼 Experience section
- 🚀 Project showcase
- 📩 Contact form
- 📄 Resume access
- 🔗 GitHub and LinkedIn integration
- ⚡ React + Vite frontend
- 🔌 REST API powered by Node.js and Express
- 🗄️ MongoDB database integration
